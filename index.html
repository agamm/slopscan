slopscan

Finds AI-slop UI patterns on any page and marks them in place. 31 deterministic rules over computed CSS. No network, no tracking, nothing leaves the page.

slopscan ← drag this to your bookmarks bar

Install

  1. Show the bookmarks bar (Cmd/Ctrl + Shift + B).
  2. Drag the black slopscan button onto it.
  3. Open any site and click the bookmark.

Reading it

Red outlineP0 — screams AI on sight
Amber outlineP1 — the obvious smell
Blue outlineP2 — cosmetic
Click a HUD rowisolate that rule
Click a labellog the element, scroll to it
Escaperemove the overlay

If the bookmarklet does nothing

Some sites block javascript: bookmarks via Content Security Policy. Paste dist/slopscan.js into the devtools console instead. In Chrome you may need to type allow pasting once first.

The score is a weighted sum of first-guess weights, not a fitted model. Read the rule list, not the number. Distribution signals (radius, spacing, type scale) discriminate well; single-face and single-feature checks are advisory. Bookmarklet is 39.5 KB.
